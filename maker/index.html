개념 도감 만들기

몬스터 그림·이름·문제 사진·정답을 넣고 게임 파일 만들기를 누르면, 학생들에게 나눠 줄 게임 파일(.html) 하나가 내려받아집니다. 컴퓨터의 크롬이나 엣지에서 사용하세요.

  1. 1단계게임 제목과 설정을 정해요
  2. 2단계몬스터마다 그림·이름을 넣어요
  3. 3단계문제 사진과 정답을 넣어요
  4. 4단계미리 해 보고 게임 파일을 만들어요

게임 설정

문제를 맞히면 이 도구를 던져 몬스터를 잡아요. "정답! 포획 도구를 던졌다!"처럼 나옵니다. 그림을 넣지 않으면 빈 칸(점선)으로 보여요.

여러 장 한꺼번에: 몬스터 그림은 파일 이름이 몬스터 이름이 됩니다(예: 빙고판.png → 빙고판). 문제 사진은 파일 이름 순서대로 문제가 비어 있는 몬스터에 차례로 들어갑니다.
