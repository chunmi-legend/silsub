개념 도감 만들기

몬스터마다 그림·이름과 문제 3개를 넣고 게임 파일 만들기를 누르면, 학생들에게 나눠 줄 게임 파일(.html) 하나가 내려받아집니다. 학생이 문제를 맞힐 때마다 몬스터의 HP가 깎이고, HP가 낮을수록 포획 도구를 던졌을 때 잘 잡힙니다. 컴퓨터의 크롬이나 엣지에서 사용하세요.

  1. 1단계게임 제목과 설정, 포획 도구를 정해요
  2. 2단계몬스터마다 그림·이름을 넣어요
  3. 3단계몬스터마다 문제 3개와 정답을 넣어요
  4. 4단계미리 해 보고 게임 파일을 만들어요

게임 설정

배경 음악지도를 돌아다닐 때 반복 재생
배틀 음악몬스터를 만났을 때 반복 재생

mp3 같은 음악 파일을 넣으세요. 음악은 게임 파일 안에 그대로 들어가서 1곡에 3~5MB쯤 늘어납니다. 학생 화면 오른쪽 위의 '소리 켜짐' 버튼으로 끌 수 있어요.

학생이 "포획 도구를 던졌다!"처럼 보게 됩니다. 그림을 넣지 않으면 빈 칸(점선)으로 보여요.

여러 장 한꺼번에: 몬스터 그림은 파일 이름이 몬스터 이름이 됩니다(빙고판.png → 빙고판). 문제 사진은 파일 이름 순서대로 빈 문제 칸에 차례로(1번 몬스터 문제 1·2·3 → 2번 몬스터 문제 1…) 들어갑니다.

정답 방식 · 번호: 문제 사진 안에 보기가 있고 학생이 번호를 누릅니다. · 기술: 보기를 글자로 적으면 배틀 화면에 기술 버튼(예: 1.일렉트릭볼 2.백만볼트…)처럼 나옵니다.
